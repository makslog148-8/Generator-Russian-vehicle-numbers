# Конструктор номеров России

Локальное приложение для Windows, которое создаёт макеты российских номерных знаков разных типов: автомобильных, мотоциклетных, прицепов, такси, полиции и военных. Номер собирается визуально: буквы, цифры, код региона, флаг и надпись `RUS`. Готовый макет можно скачать в PNG или SVG либо отправить на печать. Интерфейс намеренно сделан простым, минималистичным и примитивным.

## Готовое приложение для Windows

В папке лежит `Конструктор номеров.exe` — самостоятельная сборка для Windows. Двойной щёлчок запускает приложение без установки и без интернета.

- Все файлы конструктора находятся внутри exe.
- Рядом с exe не нужны HTML, CSS, JavaScript или шрифты.
- Настройки, размеры, выбранный тип номера и тема сохраняются в `%LOCALAPPDATA%\RussianPlateDesigner`.
- Экспорт PNG и SVG открывает обычный диалог сохранения Windows.
- Кнопка «Печать» открывает страницу печати в браузере по умолчанию: там можно распечатать номер или сохранить PDF.
- Нужен компонент **Microsoft Edge WebView2 Runtime**. В Windows 10 и 11 он обычно уже установлен; если нет, его можно скачать с сайта Microsoft.
- При первом запуске Windows SmartScreen может показать предупреждение о неизвестном издателе. Нажмите «Подробнее» → «Выполнить в любом случае».

## Возможности

- Простой интерфейс в стиле обычного приложения Windows.
- Выбор типа номера: **Автомобиль**, **Мотоцикл**, **Прицеп**, **Такси**, **Полиция**, **Военные**.
- Для каждого типа автоматически меняются поля, формат, размер и оформление номера.
- Светлая и тёмная тема; переключатель находится в правом верхнем углу, выбор сохраняется.
- Живой предпросмотр номера: стандартные типы — **520 × 112 мм**, мотоциклетный — **245 × 185 мм**.
- Редактирование серии, номера и кода региона.
- Подсказка названия региона по коду; для военных номеров — название военного округа или ведомства.
- Все буквы русского и английского алфавита: строчные автоматически становятся заглавными.
- Случайный номер и сброс настроек для выбранного типа.
- Флажок России и надпись `RUS` включаются отдельно. Для такси, полиции и военных флаг не предусмотрен, поэтому его переключатель отключается.
- У такси жёлтый фон, у полиции синий, у военных чёрный.
- Экспорт PNG в **300** или **600 DPI** либо с произвольным размером в пикселях.
- Галочка **«Сохранять пропорции»** автоматически подстраивает высоту под ширину и наоборот; при снятой галочке ширина и высота задаются независимо.
- Экспорт векторного SVG с физическим размером выбранного типа.
- PNG и SVG сохраняются через системный диалог Windows.
- Печать или сохранение в PDF через диалог браузера.
- Прозрачный фон для PNG/SVG.
- Настройки сохраняются в профиле WebView2.

> Стандартный автомобильный номер использует только 12 букв: `А, В, Е, К, М, Н, О, Р, С, Т, У, Х`. Остальные буквы добавлены для макетов и дизайна.

## Типы номеров

| Тип | Размер | Формат | Оформление |
| --- | --- | --- | --- |
| Автомобиль | 520 × 112 мм | `E 000 KX`, код `102` | белый фон, флаг и `RUS` |
| Мотоцикл | 245 × 185 мм | `0000 KX`, код `102` | две строки, белый фон, флаг и `RUS` |
| Прицеп | 520 × 112 мм | `KX 0000`, код `102` | белый фон, флаг и `RUS` |
| Такси | 520 × 112 мм | `KX 000`, код `102` | жёлтый фон, без флага, с `RUS` |
| Полиция | 520 × 112 мм | `E 0000`, код `102` | синий фон, белые символы, без флага, с `RUS` |
| Военные | 520 × 112 мм | `0000 KX`, код `43` | чёрный фон, белые символы, без флага, с `RUS` |

## Запуск

1. Откройте папку проекта.
2. Дважды щёлкните `Конструктор номеров.exe`.

Установка не требуется. Приложение работает локально и не обращается к интернету.

## Горячие клавиши

- `Ctrl/Cmd + S` — скачать PNG.
- `Ctrl/Cmd + Shift + S` — скачать SVG.

## Экспорт

| Формат | Параметры |
| --- | --- |
| PNG 300 DPI, 520 × 112 мм | 6 142 × 1 323 px |
| PNG 600 DPI, 520 × 112 мм | 12 283 × 2 646 px |
| PNG 300 DPI, 245 × 185 мм | 2 894 × 2 185 px |
| PNG 600 DPI, 245 × 185 мм | 5 787 × 4 370 px |
| PNG, свой размер | ширина и высота в пикселях; пропорции можно сохранять или отключить |
| SVG | 520 × 112 мм или 245 × 185 мм, векторные контуры |
| PDF / печать | страница выбранного типа без полей |

Пресеты `300` и `600 DPI` автоматически пересчитываются под выбранный тип номера. Для PDF в диалоге печати выберите «Сохранить как PDF». Если принтер не поддерживает нестандартный размер страницы, включите масштабирование в настройках печати.

## Технические детали

- Светлая/тёмная тема меняет только интерфейс; сам номер и экспортируемые файлы не зависят от темы.
- Размеры номера: стандартные типы — `520 × 112 мм`, мотоцикл — `245 × 185 мм`. Одна единица SVG равна одному миллиметру.
- Высота основных символов стандартного номера: `76 мм`; код региона: `58 мм`; `RUS`: `20 мм`. Мотоциклетный номер использует отдельную двухстрочную компоновку.
- Размер PNG можно задать в пикселях: ширина от `100` до `20 000` px. Максимальная высота зависит от типа: `4 308` px для номера `520 × 112` и `15 102` px для мотоциклетного. При включённой галочке «Сохранять пропорции» второе поле пересчитывается автоматически. Если галочка снята, PNG заполняет указанные ширину и высоту полностью (изображение может растягиваться).
- Глифы — векторные контуры из шрифта `GOST-R-50577-93.ttf`, преобразованные в `assets/glyphs.js`. Во время работы шрифт не требуется. В наборе 69 глифов: цифры, латиница `A–Z`, кириллица `А–Я` и `Ё`.
- Основная надпись центрируется в поле до разделителя, код региона — в правом поле. У мотоциклетного номера цифры расположены сверху, а буквы и код региона — снизу.
- Названия регионов хранятся в объекте `REGIONS` в `app.js`, военные коды — в `MILITARY_CODES`. Коды без названия всё равно отображаются на номере.
- Настольная версия собрана PyInstaller в один exe. При запуске файлы распаковываются во временную папку, поэтому первый запуск может занять несколько секунд. Профиль WebView2 хранится отдельно и не удаляется при закрытии приложения.

Папка `source` не нужна для запуска готового приложения. Она содержит исходники и всё необходимое для пересборки exe файла.

## Сборка exe

Для пересборки нужен Python 3.10+ и интернет для установки пакетов. Откройте папку `source` и выполните:

```bash
python -m pip install -r requirements-desktop.txt
python -m PyInstaller --noconfirm --clean russian-plate-designer.spec
```

Или просто запустите `source\build-exe.bat`. Готовый файл появится в `source\dist\RussianPlateDesigner.exe`; скрипт также копирует его в `source\RussianPlateDesigner.exe`.

Чтобы заменить готовое приложение, скопируйте новый exe в корень проекта и переименуйте его в `Конструктор номеров.exe`.

Настольная оболочка использует `pywebview` и Microsoft Edge WebView2. Приложение остаётся полностью локальным: HTML, CSS, JavaScript и глифы встроены в exe.

## Шрифт и лицензия

Шрифт `GOST-R-50577-93.ttf` взят из проекта [stanlapru/rus-carplates-font](https://github.com/stanlapru/rus-carplates-font) и распространяется по лицензии **Do What You Want Public License**. Текст лицензии находится в `source/assets/fonts/LICENSE.txt`.

Контуры глифов в `source/assets/glyphs.js` созданы на основе этого шрифта. Код приложения можно свободно использовать и изменять.

## Важно

Приложение не является официальным сервисом и не связано с ГИБДД. Это конструктор макетов для дизайна, презентаций и полиграфии. Не используйте созданные изображения для изготовления реальных регистрационных знаков или документов.
